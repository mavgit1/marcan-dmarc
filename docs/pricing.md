# Pricing

Marcan is free software for everyone, companies included: every feature is in the public code, and nothing is held back for a paid edition. The license asks one thing, and only of an operator who runs Marcan for clients: tell each client that the service runs on software whose source code is freely available, that they may run it themselves, and where to get the source. An operator license replaces that duty. Who counts as a client is on the [License](./license#domains-of-clients-tell-them-or-buy-a-license) page.

## What a key changes

When you subscribe, you receive an operator key. It changes the attribution and nothing else: the From name of the emails, their letterhead, their last line (the free-software notice becomes "Sent by Acme IT.") and the line under "Marcan" in the sidebar. It unlocks no feature and lifts no limit: every feature works the same without a key, and nothing is hidden or blocked. The details, with examples, are under [What a key changes](./license#what-a-key-changes).

## Entering the key

Enter the key under **Settings → License → Operator key** and save. The notice is off at once and stays off while the key is stored. The key is checked inside Marcan, never online. See [The operator key and the notice](./license#the-operator-key-and-the-notice).
